# Consumer Sales & Demand Forecasting Platform

 ## Project Overview
An end-to-end retail analytics and demand forecasting platform built using real-world retail data. The project demonstrates industry-grade data cleaning, SQL-based dimensional modeling, analytics, and forecasting.

##  Tools & Technologies
- Python (Pandas, NumPy)
- PostgreSQL (Star Schema, Fact & Dimension tables)
- Power BI (Interactive dashboards)
- Excel (Validation & exploratory analysis)
- Machine Learning (Demand forecasting)

##  Key Features
- Data cleaning & feature engineering
- Retail star schema design
- Sales & demand analytics using SQL
- Forecast-ready dataset for ML models
- Business-ready Power BI dashboard
